# Batter Discomfort Index (BDI)

A per-pitch-type metric that measures how uncomfortable a pitch makes a batter, built from two components: disruption to the batter's swing mechanics relative to their own baseline, and disruption to their swing-decision behavior outside the strike zone.

Most existing pitch-quality metrics (Stuff+, pitch-level xwOBA, etc.) score a pitch by its physics — velocity, spin, movement — without accounting for what the pitch actually does to the hitter facing it. BDI is built the other way around: everything is measured against how much a specific batter's own normal swing and chase behavior gets disrupted.

**Data:** 2025 MLB season (regular season + postseason), pulled via [pybaseball](https://github.com/jldbc/pybaseball) from Baseball Savant Statcast — 726,142 total pitches.

**Headline validation result:** BDI was regressed against held-out xwOBA (never used in training) across 1,004 pitcher/pitch-type combinations — R² = 0.152, r = −0.390, p < 0.001.

## Pipeline

Scripts are run in this order. Each reads from and writes to the same working directory.

| Step | Script | What it does |
|---|---|---|
| 1 | `batter_discomfort_index.py` | Pulls all 2025 Statcast pitch data month-by-month (to avoid server timeouts) and saves it to disk. |
| 2 | `build_tables.py` | Builds the pitcher pitch-type summary (→ `pitch_summary_2025.csv`) and each batter's pitch-type-specific baseline (→ `batter_baseline_2025.csv`), with minimum sample thresholds of 30 swings / 20 outside-zone pitches. |
| 3 | `join_deviation.py` | Computes per-swing mechanics deviation (z-scored within pitch type) and per-pitch chase deviation, each relative to the batter's own baseline from step 2. |
| 4 | `build_discomfort_score.py` | Two-stage model: Stage 1 regresses launch speed on swing-mechanics deviation to derive physics weights; Stage 2 regresses whiff rate on the combined physics + chase scores to produce the final BDI. Also runs the held-out validation against xwOBA. Outputs `discomfort_leaderboard_2025.csv`. |
| 5 | `regress_by_pitch_type_v2.py` | Companion analysis: regresses BDI score on pitch physics (velocity, spin, movement, extension) separately per pitch type, handedness-adjusted. Outputs `physics_regression_standardized_2025.csv`. |

`regress_by_pitch_type.py` is an earlier version of step 5, kept for reference — `_v2.py` is the current one, with the handedness adjustment applied. `check_pitch_type.py` is a diagnostic utility used during development to inspect pitch-type labeling and counts, not part of the main pipeline.

> Note: the raw per-pitch Statcast pull (~726K rows) and a couple of large intermediate files (per-swing deviation, per-pitch chase deviation) aren't included in this repo due to size — they're regenerated by running steps 1–3 above.

## Output data

| File | Contents |
|---|---|
| `pitch_summary_2025.csv` | Pitcher-level summary per pitch type — velocity, spin, movement, whiff/chase rates. |
| `batter_baseline_2025.csv` | Each batter's pitch-type-specific baseline swing metrics and chase rate. |
| `discomfort_leaderboard_2025.csv` | Final BDI scores per pitcher/pitch-type, with physics score, chase deviation, and validation outcomes. |
| `physics_regression_standardized_2025.csv` | Standardized physics-vs-BDI regression coefficients, per pitch type. |
| `physics_regression_by_pitch_type_2025.csv` | Same regression from the earlier (non-standardized) script version. |
| `deviation_by_pitch_type_2025.csv` | Swing deviation metrics aggregated by pitch type. |
| `discomfort_preview_2025.csv` | Sample/preview output used during development. |
